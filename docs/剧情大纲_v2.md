# 思源村探案 · 剧情大纲（修订版 v2）

> 基于《田原-思源村跑团设定》原始文档，针对"平淡感、层次不足"问题进行全面修订。
> 修订原则：**保留原有骨架，增加反转层、道德灰度、倒计时张力、线索推理链**。

---

## 0. 设计理念

### 0.1 原版问题诊断

| 问题 | 表现 |
|------|------|
| **真相一目了然** | 两个NPC都在疯狂暗示"水有问题"——村长过度否认（此地无银）、林德山狂热赞美"圣水"。玩家还没调查就知道答案了 |
| **缺少反转层** | 真相只有一条直线：利库伊是邪神→水被污染→道士是坏人。没有"以为接近真相却发现还有更深一层"的体验 |
| **NPC动机扁平** | 村长=被蒙蔽好人、林德山=疯子受害者、道士=纯坏人、隐士=待定好人。所有角色都是单面的 |
| **缺少倒计时** | 唯一的压力是污染度达到6触发迷途结局，但玩家感受不到时间紧迫和"不行动就有代价" |

### 0.2 修订方案总览

| 维度 | 原版 | 修订版 |
|------|------|--------|
| 反转结构 | 1层（利库伊=邪神） | **3层**（邪神→堕落封印者→幕后真凶） |
| 村长 | 被蒙蔽的好人 | **善良但无奈的保护者：对村民睁一只眼闭一只眼，对外来者善意劝离** |
| 林德山 | 完全疯癫的受害者 | **半疯半醒的记录者，疯话里藏真话** |
| 道士 | 纯粹的邪教教主 | **堕落的封印者，半人半傀儡** |
| 隐士 | 净化线盟友 | **伪装成盟友的幕后真凶**（原版隐士是真盟友，改为最终反转） |
| 污染度 | 纯数字 | **每级有可感知的异常表现** |
| 结局 | 8种（信仰/游说二分） | **10种**（新增封印结局、真相结局，细化抉择层次） |

## 1. 世界观与背景设定

### 1.1 田原村

田原村，藏在西南深山的古老村落，距离最近的县城也得爬过数百里山路。山水环抱、绿林掩映的密林深处，村民们过着自给自足的生活。传闻早在晚唐年间，这里便开始有人定居，并形成了别具一格的文化。村民们用竹筒接引山泉，修建水渠灌溉农田，如桃花源般与世隔绝。

村中有**思源湖**，湖水来自后山地下水系。湖边有小亭子，是林德山的居所。村口有村长家大宅，是玩家进入村子的第一站。

### 1.2 利库伊之神

利库伊是一种以水流为扩散渠道的**远古诡异力量**。

#### 1.2.1 本质（修订：增加"封存意识"设定）

> **原版**：利库伊是纯粹的邪神，主动作恶。
>
> **修订**：利库伊是一个远古被封存的"意识体"——它并非传统意义上的"邪恶神明"，而更像是一种**本能扩散的寄生力量**。它没有主观恶意，但它的存在本身就是污染。它"渴望"扩大领地、吸纳信徒，就像癌细胞"渴望"增殖——不是出于恨，而是出于本能。
>
> 这个设定让利库伊无法被"消灭"——你只能重新封印它，或者与它共存。这为结局增加了道德抉择的深度。

- **具象表现**：利库伊存在于一切污染的水源中，山洞中的水潭是它常待的地方。黑色粘稠物是利库伊的实体痕迹——一切黑色粘稠物都是它经过的痕迹。
- **力量规则**：
  1. 信仰利库伊的人越多，利库伊力量越强，扩散速度越快、范围越广
  2. 利库伊的污染可以影响人的认知，让人发现不了水源被污染
  3. 对忠诚稳定的信徒（如村民），利库伊需要他们维持和传播力量，不会迫害其生命
  4. 对存在风险的信徒（如玩家），利库伊会直接吞噬以获得力量——**玩家比村民更危险**
  5. 对叛逆的异教徒，利库伊会利用信徒或自然因素进行污染

#### 1.2.2 污染表现分级（原版保留，补充可感知细节）

## 3. 职业系统

### 3.1 工匠（樟谊轩第六代传人）

**背景**：百年家具行樟谊轩传人，精通火燎定形法等古法木工。母亲是外乡人，嫁妆里裹着半箱旧书，劝父亲让他去城里读书。考入交大设计学院，在城市拉到投资准备发展樟谊轩。听闻家乡水系污染，投资人撤资，连夜回乡。

**支线任务**：调查母亲提到的"意外"——即2014年父亲误判甘母艾芝为黑心资本家、劝村民不救、间接害死她的往事。父亲因此沉默寡言。

- **技能1**：观察敏锐，能发现别人难关注的细节
- **技能2**：艺术底蕴丰厚，身上弥散木香，喜好传统文化的人对你有好感
- **特殊能力**：随身工具包和木料，可制造钥匙、匕首、手办等
- **支线**：调查父亲性情大变的"意外"真相（公众号谜题：密码1=4396，密码2=1021）

### 3.2 财阀（甘氏集团第三代继承人）

**背景**：甘氏集团看中田原村地脉价值，三亿美金度假村蓝图已铺开。但河水异常浊流让水质报告飘红。母亲艾芝在田原村考察时被道士施法害死，财阀此次前来既是商业考察也是为母复仇。母亲留下的艾草和《木经》残卷是线索。

**支线任务**：调查母亲艾芝去世的真相。需要找到母亲生日（19760320）、旧医院名称（干水固）、甘父手机号（394729387）。

- **技能1**：见多识广，能辨识新奇事物
- **技能2**：器宇轩昂，谈吐不俗，交际能力和说服能力强
- **特殊能力**：纯金金币，识货的人能为之做牛做马
- **支线**：三段解锁——日记残章（母亲生日）、诊疗单（医院名称）、甘父通话（手机号）

### 3.3 运动员（泳坛新星）

**背景**：出生在田原村，儿时在河中游泳长大。父亲曾是游泳健将，2000年在河中救下一个顺流漂来的竹篮婴儿（即"医生"角色），腿部受伤无法再游泳。父亲发现河水异常，极力送运动员去县城训练。亚运会夺冠后回乡拍摄写真，发现水质严重污染。

**支线任务**：解开父亲的心结。父亲留下一把锁着的盒子（答案：上海游泳馆），内有报名证明和两份日记——日记记录了河水异常的发现，以及2000年救起婴儿的往事。

- **技能1**：体质出色，力量强健，尤其擅长游泳
- **技能2**：乡野长大，认得家乡一草一木，能从自然中发现细节
- **特殊能力**：田原村是家乡，很多人与你相熟
- **支线**：解开父亲心结，发现医生就是当年救起的婴儿

### 3.4 网红（千万粉丝旅行博主）

**背景**：收到匿名粉丝来信推荐田原村作为取景地。调研时发现田原村神秘水污染的帖子。自出生以来非常讨厌水，常梦见浑浊旋涡和深黑海底。**真相**：道士李乐水伪造信件骗网红来田原村（字迹比对可证实）。网红婴儿时期父母带她去中东旅游，有老婆婆指她喊"被利库伊诅咒的人"。网红与利库伊有某种宿命联系。

**支线任务**：找寻为什么对田原村有熟悉感，匿名粉丝是谁。通过公众号谜题解锁童年记忆——网红被利库伊诅咒标记，注定要来此面对邪神。

- **技能1**：全网千万关注，交流能力出众，人格魅力强，村里有粉丝
- **技能2**：擅长跋山涉水，野外生存技能堪比特种兵
- **特殊能力**：照相机、无人机、登山绳
- **支线**：解锁网红liquid的童年记忆，发现道士骗她来的真相

### 3.5 医生（三村九寨唯一的白大褂）

**背景**：毕业后来到深山成为乡村医生。养父曾是乡间劳工，见到亲友艰难抗病去世后苦读医书行医救世。**医生就是2000年山洞事故遇难者龚泽的儿子**——母亲王芳早产后自缢，将婴儿放入竹篮随河漂流，被运动员父亲救起后由他人收养（养父即是从劳工转为乡村医生的人）。

**支线任务**：调查出生地和生父生母与养父的故事。需要找到生父姓名（龚泽）和小灵通密码（134），解锁事故现场录音和新闻报道。

- **技能1**：卓越的医学和药理学知识，中西贯通，略懂植物学
- **技能2**：辅修心理学，行医已久，能察言观色
- **特殊技能**：携带药物和简易医疗器械，可急救
- **支线**：发现自己是龚泽之子，运动员父亲是救命恩人。**关键发现**：干燥剂可消退利库伊污染导致的肿胀（在工头老龚身上验证），游说判定+1

## 4. NPC角色设定（修订版）

### 4.1 村长 吴志源

#### 原版设定
被蒙蔽的好人。道士救了村里老人后皈依利库伊，深信不疑。绝不承认水有问题。

#### 修订设定：善良但无奈的保护者

```
村长其实并非完全被蒙蔽。

2012年烧鱼宴之后，村里几个原本对河水有疑虑的人突然不再质疑了——
村长注意到了这个异常。2015年甘艾工厂因水质太差退出时，他拿到了
工厂的水质检测报告，白纸黑字写着"重金属超标、不明有机物"。

村长是一个善良的人。他不是不知道水有问题，但他更清楚一件事：
田原村太偏了，"干水固"医院倒闭了，外界的医疗和资源到不了这里。
没有利库伊的"庇佑"，村里老人病痛发作了谁来管？庄稼歉收了谁来救？
他见过2011年大饥荒时村里人饿死的惨状——是道士和利库伊救了村子。
所以他选择了睁一只眼闭一只眼：对村民，他假装一切正常，
因为利库伊确实让这个偏远村子活了下来；他不是在"作恶"，
他是在"让村子活下去"和"面对真相"之间选了前者。

但对远道而来的外乡人，村长的态度完全不同——
他发自内心地不希望这些年轻人被污染。
所以他对玩家温和友善但不过分热情，不像村里人那样拉人喝"圣水"。
如果玩家想要调查村子水相关的情况，村长会真诚地劝他们别查了、
尽快离开——"你们是外乡人，这地方的事不是你们能管的，
趁着天还没黑，早点下山去。"
这不是威胁，是一个老人对年轻人的善意保护。

他绝不主动给玩家喝河水，如果玩家问到水，他会岔开话题。
后院食堂的菜是他特意让人用山上泉水浇的（不是河水），
他自己喝河水，但他给客人准备的是"干净水"。

保险柜里的猎枪，不是防隐士的，也不是给自己留的"最后手段"——
是万一利库伊彻底失控、村民被深度污染失去理智时，
他需要一样东西保护外乡人安全离开村子。
钥匙交给萱萱保管，是因为他怕自己年老手抖，关键时刻开不了锁。
```

**戏剧效果**：玩家会发现村长的"劝离"不是心虚，而是真心实意的保护。他对村民的沉默不是冷血，而是"让村子活下去"的无奈选择。这让村长成为一个令人心酸的角色——他什么都知道，但他没有别的办法。当玩家出示铁证时，他不会崩溃，而是会叹口气说："所以我才劝你们走啊。"

#### 关键变化

| 原版 | 修订版 |
|------|--------|
| 绝不承认水污染，因为真的不知道 | 绝不承认水污染，因为**知道但选择睁一只眼闭一只眼**。如果玩家出示铁证，村长不会崩溃，而是叹气："所以我才劝你们走啊。" |
| 猎枪是防隐士的 | 猎枪是**万一失控时保护外乡人安全离开的武器** |
| 对玩家热情爽朗、拉人融入村子 | 对玩家**温和友善但不过分热情**，主动劝玩家别查水的问题、尽快离开 |
| 被劝说是"幡然醒悟" | 被劝说是**"终于有人能替村子做点什么了"**——他一直知道这样下去不行，但他自己做不到 |

### 4.2 河边老大爷 林德山

#### 原版设定
完全疯癫的受害者。儿子小满死于2000年山洞事故，从此崩溃。2005年被道士所救后狂热信仰利库伊。

#### 修订设定：半疯半醒的记录者，疯话里藏真话

```
林德山没有完全疯。

他的"疯癫"一半是真——利库伊的低语确实在他耳边回响，
让他分不清现实与幻象。但另一半是伪装——
在疯癫的外表下，他一直在秘密记录利库伊的变化。

他有整整一本"疯话日记"，表面上写的是利库伊赞美诗和预言，
实际上用隐语记录了：
- 2005年到现在的水质变化（甜味越来越浓）
- 村民身体异常（肿胀程度逐年加重）
- 道士行为的异常（清醒时会犹豫，被控制时会流畅）
- 后山山洞的水位变化（每年涨一点点）

他的"预言"不全是利库伊低语——有一部分是他自己的推理。
他预言"下游会死鱼"，是因为他推理出污染会扩散。
他预言"有人会来"，是因为他知道外界迟早会注意到。

他一直在试图警告外人，但用了隐晦的方式——
疯话里藏着真话，只有有心人才能解码。
比如他反复念叨的"海又升起，让水淹没"，
表面是利库伊经文，实际是他对思源湖水位上升的观察记录。

他不敢公开反对道士，因为他害怕。
他也不敢完全清醒，因为清醒意味着要面对2000年那天——
他亲眼看到黑色粘稠物从破碎的青铜鼎中涌出，
听到不属于这个世界的低频嘶叫，
而他的理性、他的学识、他引以为傲的"文曲星"大脑，
完全无法解释这一切。那种理性崩塌的恐惧比任何东西都可怕。
疯癫是他的盔甲，也是他的牢笼。
```

**戏剧效果**：玩家如果细心，能从林德山的"疯话"里解码出真实线索。他不是单纯的info dump NPC，而是一个"需要玩家赢得信任才能解锁真相"的角色。当玩家用他的疯话逻辑反问他时，他会短暂露出清醒的眼神。

#### 关键变化

| 原版 | 修订版 |
|------|--------|
| 疯话全是利库伊低语 | 疯话一半是低语，一半是**加密的真实信息** |
| 被问小满时1句真情流露即回疯癫 | 被问2000年事故时，如果好感够高，会用"疯话"暗示事故不是意外——"是有人告诉他们那里有宝贝的" |
| 预言全是利库伊低语 | 预言**一半是低语，一半是他自己的推理**——玩家可以验证 |

### 4.3 道士 李乐水

#### 原版设定
纯粹的邪教教主。2010年来村，通过作法获取信任，传播利库伊信仰，每周带村民献祭。

#### 修订设定：堕落的封印者，半人半傀儡

```
李乐水原本是正一道的正式传人。

他师父临终前告诉他：西南深山有一处远古封印正在松动，
如果完全破裂，被封存的"水之意识"将重见天日。
2010年，他来田原村的目的是重新加固封印。

但在后山山洞的封印仪式中，他低估了利库伊的侵蚀力。
青铜鼎已经破碎，利库伊的力量远超预期。
仪式失败，他被利库伊反向控制。

他现在处于"半人半傀儡"状态：
- 清醒时他会试图帮助玩家（给出隐晦提示）
- 被利库伊控制时他会阻碍玩家，组织献祭，传播信仰
  这时的他眼神空洞，动作流畅得不自然

玩家需要判断他哪句话是人说的，哪句是神说的。
他内心深处知道自己已经无法回头——
他最大的恐惧不是死亡，而是"彻底失去自我"。

2014年他对甘母艾芝施法，是在被完全控制的状态下做的。
清醒后的他对此一无所知，但如果玩家告诉他，
他会陷入极度的痛苦和自我厌恶。

他现在每周带村民去山洞"献祭"——
清醒时他试图减少献祭的频率和规模，
被控制时他会变本加厉。
```

**戏剧效果**：道士不是"打败就赢了"的BOSS，而是一个"拯救还是消灭"的道德抉择。杀了他，利库伊可能失控（失去封印者的制衡）；不杀他，他可能继续传播污染。玩家如果发现他的双重状态，可以选择在清醒时与他合作。

#### 关键变化

| 原版 | 修订版 |
|------|--------|
| 纯粹的邪教教主 | **堕落的封印者，半人半傀儡** |
| 写匿名信骗网红来是为了献祭 | 清醒时写的信**包含隐晦的警告**（"当心穿蓝衣黑裤的人"=他自己） |
| 对甘母施法是主动作恶 | 对甘母施法是**被完全控制时所为**，清醒后不知情 |
| 击杀=净化线的必要条件 | 击杀或**拯救**都可能通向不同结局 |

### 4.4 隐士 / 神秘人

#### 原版设定
净化线主要NPC。隐士曾独自入山修炼，归来发现村庄巨变，暗中调查试图帮助村民。是玩家的盟友。

#### 修订设定：伪装成盟友的幕后真凶（最终反转）

```
【这是整个故事最大的反转。以下内容是DM/开发者视角，玩家不应提前知晓。】

隐士的真实身份：他是2005年"出走修炼"的那个人。
但他的"修炼"不是什么正经修行——
他是利库伊的原始信徒之一，甚至可能是最后一个
记得如何完全释放利库伊的人。

2000年山洞事故的真相不只是"意外"：
隐士在事故前就来到了田原村附近。他知道后山山洞中封印着利库伊，
也知道青铜鼎的位置（他从古籍中找到的）。
但他自己无法进入山洞——封印对"有恶意意图的人"有防御，
而且他一个人的力量不够。

于是隐士在田原村附近的乡镇散布消息：
"田原村后山里有珍贵的青铜文物，非常值钱，
随便挖出来一件就够一辈子吃穿不愁。"
他把消息说得言之凿凿，甚至伪造了一些"出土文物"的碎片
作为证据，在黑市上流通。

消息传到了一支施工队耳中。工人们都是一穷二白的底层人，
听到"山里有宝贝"的传闻，起了贪念，便以"开发山洞"为名
来到田原村施工。陆羽和龚泽在挖掘中果然发现了青铜鼎，
试图搬出去卖钱——这才导致了坍塌和青铜鼎破碎。

隐士的计划是让施工队击碎青铜鼎释放利库伊。
但他没想到山洞会坍塌，也没想到利库伊释放时的力量如此恐怖——
黑色粘稠物涌出，不存在的低频嘶叫响彻山谷。
施工队5人当场死亡，利库伊重见天日。

但利库伊的释放不够完全——
因为工人的死是意外坍塌而非献祭，
他们的血没有流入鼎中完成仪式。

所以隐士2005年"出走修炼"——
他去学习如何完成利库伊的完全苏醒仪式。
完全苏醒需要一个条件：足够多的信徒同时献祭，
而且必须有一个"被利库伊标记的人"自愿走入水潭。

隐士2010年回来后，发现道士先到了一步——
道士试图封印利库伊，反而被控制了。
隐士将计就计，利用道士的"半人半傀儡"状态：
- 被控制时的道士传播信仰（正合隐士意）
- 清醒时的道士试图封印（隐士暗中破坏他的封印材料）

隐士对玩家表现得友善、理性，提供"准确"的信息——
利库伊是邪神、水被污染、道士有问题——这些都是真的。
所以玩家会信任他。

但隐士给玩家的"帮助"，是在引导玩家走向特定结局：
- 他让玩家去摧毁祭坛——因为祭坛是道士清醒时设置的抑制装置
  摧毁祭坛=移除最后的制衡=利库伊完全苏醒
- 他让玩家去找武器防身——因为"最终仪式"需要一个武装的人
  走入水潭（被利库伊标记的人+自愿+武装=完全苏醒）

被利库伊标记的人是谁？网红。
隐士知道网红被标记了，所以道士（被控制时）写信骗网红来。
隐士利用了道士的这个行为。

隐士的最终计划：
1. 让玩家信任自己（提供真信息）
2. 让玩家摧毁祭坛（移除制衡）
3. 让网红走到水潭边（标记+到场）
4. 利用污染度或谎言让网红"自愿"走入水潭
5. 利库伊完全苏醒

破绽（玩家可以发现的关键线索）：
- 隐士说"摧毁祭坛"可以净化利库伊——但林德山的疯话日记里
  记录了"祭坛是在抑制水潭水位上涨"，摧毁祭坛反而会让水位暴涨
- 隐士2005年"出走修炼"——但2005年大旱时他为什么要走？
  真正想拯救村子的人不会在最困难的时候离开
- 工头老龚的日记里提到"2000年事故前有个陌生人在村子附近转悠"
  ——那个人就是隐士
- 运动员父亲的日记提到"2000年河里飘来婴儿"——但婴儿是4月15日事故后
  5月10日才出生的。时间线不对。这说明有人在事故后还在山洞附近活动
  ——那个人也是隐士
```

**戏剧效果**：这是最强的反转——玩家最信任的"盟友"才是最危险的人。所有"帮助"都是陷阱。当玩家发现真相时，可能已经摧毁了祭坛、把网红带到了水潭边。

> **注意**：这个反转不影响原版的"净化线/邪教线"二分结构。净化线的最终目标仍然是山洞，但"摧毁祭坛"不再是正确做法——正确做法是**修复祭坛**或**重新封印**。隐士会误导玩家摧毁祭坛，玩家需要自己判断。

#### 原版隐士互动（保留+修改）

隐士对各职业的前置任务和交流**保留原版框架**，但在最终阶段（③最终地点）修改：

| 原版 | 修订版 |
|------|--------|
| 隐士引导玩家去山洞摧毁祭坛 | 隐士引导玩家去山洞"摧毁祭坛"——**但这是陷阱** |
| 净化线=跟随隐士摧毁祭坛 | 净化线=发现隐士的谎言后，选择**修复祭坛/重新封印**而非摧毁 |
| 邪教线=杀死隐士 | 邪教线=杀死隐士（玩家以为隐士是阻碍，实际隐士死后的利库伊更需要封印） |

### 4.5 其他NPC（保留原版+微调）

#### 木匠 穆江

日子人，皈依利库伊后从日常工作中获得巨大快乐。任务：鲁班锁。奖励：木料/木斧/梯子三选一+木簪。

#### 工头 老龚（龚忠）

外来工头，本想在山后建工程，因山路恶劣撤资。

**修订微调**：老龚是龚泽的同族兄弟/亲戚，他来田原村的真正目的是调查龚泽的死因。他的日记里记录了村里的异常。医生角色可以发现老龚身体肿胀是四年前（2021年来到这里后）开始的。**关键**：医生的干燥剂实验能消退肿胀——这是游说判定+1的来源。

### 工头老龚（龚忠）

#### 基础设定
老龚是常年承接山路、水利和隧道工程的外来工头。2021年，他来到田原村，声称准备开发后山道路，却因为山路恶劣、成本过高而放弃工程。
工程早已停摆，他仍然独自住在废弃工地，嘴上说是在等待结算设备和尾款。
真实目的，是调查同族兄弟龚泽在2000年山洞事故中的死亡真相。

### 人物特点：凡事都要有个数

老龚非常讨厌“大概”“可能”“听别人说”之类的表述。
他随身带着卷尺、铅笔和一本施工记录簿。说话时总会追问具体数字：
> “几点进去的？”
> “死了几个？你亲眼看见几个？”
> “说有个人站在山脚，离洞口多远？”
即使玩家只是随口说桌子有些歪，他也会拿出卷尺量一下。
这种习惯源于2000年的事故。官方报告中的时间、人数和坍塌方向互相矛盾，老龚坚信，只要把所有数字重新对上，就能找到龚泽真正的死因。

### 人物特点：极度厌恶潮湿

工棚里到处堆着干燥剂、生石灰和防水布。玩家身上带着雨水进入工棚时，老龚会立刻让玩家擦干鞋底。
他解释说：
> “机器受潮要坏，人待久了也一样。”
实际上，老龚来到田原村后，身体开始逐渐肿胀。每逢下雨、饮用村里的水，或者靠近思源湖，症状都会加重。
他不愿承认自己可能被村庄影响，只把这些变化归结为年龄增长和常年劳作。

## 旧工地任务：找回工具箱

老龚请玩家帮忙找回一个被泥石流掩埋的旧工具箱。
他说里面只是施工图纸和几件旧工具，但玩家找到后，可以发现工具箱曾经被人打开过，里面有三样异常物品：
1. 甘艾工厂撤离前的一页水质检测报告；
2. 一块带有人工切割痕迹的青铜碎片；
3. 一张写着2000年事故人员名单的旧纸条。
玩家将工具箱完整归还后，老龚会提供基础信息。

## 第一层信息：正常完成任务即可获得

老龚会告诉玩家：
* 甘艾工厂进驻前后，水质都存在异常；
* 工厂撤离的真正原因是水质不合格；
* 2000年的施工队听说后山藏有值钱的青铜器，因此违规进入山洞；
* 龚泽等人在搬动一只青铜鼎时遭遇坍塌。
老龚不会主动承认自己认识龚泽，只会说：
> “以前干工程的，多少都认识几个姓龚的。”

## 第二层信息：事故存在异常

### 触发条件

满足以下任意一项：
* 玩家指出青铜碎片是被人提前加工过的样品；
* 工匠发现碎石和钢架的弯曲方向由山洞内部指向外部；
* 玩家询问：“施工队怎么会准确知道青铜鼎的位置？”
* 玩家将工具箱完整归还，没有私藏其中的金币或旧物。
老龚会承认，2000年的事故不像普通坍塌。

### 木匠 穆江

#### 基础设定

穆江是樟谊轩木工世家的第六代传人，精通火燎定形、榫卯暗合等古法木工。早年被母亲送去城里读书，之后回到田原村。

穆江如今独自住在村边的木匠工坊，终日与刨花和木料为伴。他皈依利库伊后，从日常劳作中获得巨大而空洞的快乐——他感觉自己做木工不再疲惫，手却越来越不听使唤。他不知道的是，自己的手艺其实正在退步，只是利库伊的"恩赐"让他感觉不到。

穆江真正的秘密，是2014年11月那段他绝口不提的往事：他误判甘母艾芝为黑心资本家，劝村民不救，间接害死了她。这件事是他一生的愧疚来源，也是他沉默寡言的根源。

### 人物特点：对"节"的病态执着

穆江做活时有一个雷打不动的规矩——每一处榫卯、每一道纹路，都必须严丝合缝地对应他心中的"节"。

所谓"节"，是樟谊轩祖训里对木工章法的统称：木有纹理，人有节操，顺纹则成器，逆节则成废。穆江会把任何一件木器拆解成无数个"节点"来衡量：这个榫该用几分力、那道线该偏几度、这块料该来自树的哪一段。他甚至能凭手感判断一块木料是在山的向阳面还是背阴面长的。

这种执念并非祖传的匠人精神那么简单。穆江的母亲是外乡人，嫁妆里裹着半箱旧书，劝父亲让他去城里读书。穆江是整个樟谊轩六代里唯一一个"读过书"的传人，他既被父亲寄予"光耀门楣"的厚望，又被族中长辈暗中讥讽为"忘了根的读书人"。为了证明自己配得上樟谊轩的招牌，他把祖训里模糊的"节"字，变成了近乎偏执的量化标准——只要每一处"节"都对得上，他就还是那个合格的传人，那个没有辜负先祖的人。

2014年之后，这种执念变本加厉，且扭曲了方向。穆江开始把"节"从木工章法，延伸到对人事的评判上：一个人该不该信、一件事该不该做，他都要在心里量一量"节"对不对得上。甘母艾芝就是他心里"节"彻底错位的那个人——他坚信一个城里来的资本家不可能真心保护森林，这个判断像一道歪掉的榫，再也校正不回来。艾芝死后，他更加依赖这套自我惩罚式的衡量标准：只要时刻盘算"节"，他就不必直面那个"量错了人"的自己。

玩家会发现，穆江评价任何事物都用"合不合节"的说法：
> "这料子纹理是顺的，合节。"
> "你说话绕来绕去，不合节。"
> "合节的事我做，不合节的事，莫开这个口。"

这种语言习惯既是他的盔甲，也是他的牢笼——他用"节"把世界切割成可控的小块，好让自己不必面对那些无法量化的愧疚。

### 人物特点：从不直视来客的眼睛

穆江与人交谈时，目光永远落在对方的手上，或者身后的木料上，极少与人对视。

他会盯着来访者的手看很久，仿佛在判断这双手"合不合节"——是不是干粗活的、是不是干净的、是不是配碰他的木料。如果玩家伸手摸他的作品，他会立刻把东西收回。

这个习惯源于2014年11月7日那天。穆江在田原村路边撞见口吐黑血的艾芝时，两人曾对视过一眼。据他后来在日记里反复回忆，那一眼里"没有怨恨，只有困惑"——艾芝到死都不明白，为什么这个曾在林区与她并肩遴选木料的朋友，会站在路边看着她倒下。

那一眼成了穆江此后十一年里挥之不去的画面。他开始害怕与任何人对视，生怕再看见那样的眼神。他对村民解释说这是"匠人不看人，只看物"的老规矩，村里人也习惯了这位木匠说话时永远侧着脸。


## 木匠工坊任务：鲁班锁

穆江请玩家帮忙解开一只他"做了很久却总也合不上"的鲁班锁。

他说这是樟谊轩祖传的教具，用来考验学徒是否"知节"。实际上，这只鲁班锁是2006年穆江亲手做给艾芝的礼物的一部分（参见日记2012.1.10）。艾芝死后，锁被退回，穆江却再也无法把它拼合——每次拼到最后一根，他的手就会发抖。

玩家如果手巧（工匠角色，或通过检定），可以帮他把锁合上。合上的瞬间，穆江会沉默很久，然后说：
> "合节了。十年了，总算合节了。"

他会按原版规则给予奖励：木料/木斧/梯子三选一，外加一支木簪。

## 第一层信息：正常完成任务即可获得

穆江会告诉玩家：
* 樟谊轩是百年家具行，自己是第六代传人；
* 2014年村里来过一个城里女商人，想建度假村，后来"出了事"走了；
* 那之后自己就再没出过村，"外头的事，不合节，懒得管"；
* 村里的水"喝着挺顺口"，他每天打水做活，不觉着有什么问题。

穆江不会主动承认自己认识艾芝，只会说：
> "城里的客人来来去去，我记不住那么多。"

## 第二层信息：甘母艾芝之死

### 触发条件

满足以下任意一项：
* 指出穆江近年的木工作品存在手艺退步的痕迹（榫角不齐、纹路错位）；
* 玩家在工坊某处发现一缕干枯的艾草，并追问来源。

> "那事不提了。不合节。"

如果玩家继续追问，或者出示艾芝的遗物，穆江会第一次正面（虽然依旧不看人眼）说出：
> "她不是我害的，可她死的那天，我站在路边，没让她进门。"
> "我当她是来砍树的，谁知道……"

他会简要交代：2014年11月，他误以为艾芝是黑心资本家，不告而别；后来在田原村撞见她口吐黑血求救，他劝村民不要施救；12月甘父来电告知真相，他才意识到自己误判了艾芝。

但穆江会强调，他至今不明白艾芝究竟是怎么死的：
> "她吐的是黑血，不是病血。我做了半辈子木工，见过不少人受工伤，那颜色不对。"
> "可我也不敢去查。我怕查到最后，是我亲手送她走的。"

这条信息可以让玩家把艾芝之死与道士、河水异常联系起来，但穆江本人并不知道道士施法的细节。

## 隐藏秘密：陈旧的合照与木雕谜题

### 合照

穆江工坊深处的木匣里，压着一张陈旧的合照：照片上是年轻的穆江与艾芝，两人站在一排码放整齐的木料前，艾芝手里拿着那束艾草，穆江手里拿着一只木盒，两人都笑着。

合照背面刻着一个花纹，图案看似装饰，实则暗含艾芝的姓名以及其生日。

### 木雕谜题

玩家获得合照后，需要解开背面的木雕图案。解谜方式：
* 玩家直接观察出来；
* 通过智力检定（DC14）。

解开后，图案记录的是一段穆江写给自己、从未示人的话：
> "艾芝女士于甲午年（2014）十一月初七（公历11月16日）殁于田原村。
> 她临终前口述三事：一曰河水有毒，色黑气腥；二曰有一道士于河畔施法，置生灵于水中，顷刻毙命；三曰'利库伊'三字，不知所指。

这段记录是穆江根据甘父来电转述的艾芝临终遗言整理的。穆江从未告诉任何人，因为他既无颜面承认自己间接害死了艾芝，也不愿让外人知道艾芝死前还在惦记"河水"和"道士"——他怕自己"当初若肯听她一句，或许她不会死"的愧疚被坐实。


### 解锁后的信息

解开木雕谜题后，玩家可获得：

> "她到死都在查那水。我连一杯水都没给她倒过。"
> "这个'节'，我这辈子都对不上了。"

## 穆江自己的愧疚

2014年11月6日，穆江在林区无意间看到艾芝手机上甘父发来的短信，内容催促她"尽快签砍伐协议"。穆江没有问缘由，当场认定艾芝是来砍树的骗子，不告而别。

第二天（11月7日），他在田原村路边撞见口吐黑血的艾芝。村民本想施救，穆江却拦下他们，说"那是城里来的黑心商人，想破坏我们的林子，让她回城里的医院自生自灭"。村民信了他的话，放任不管。

12月13日，甘父来电，穆江才知道艾芝一直在顶住集团压力、想建自然保护区，那天去田原村也是为了考察水质。穆江意识到，自己因为一条短信、一个偏见，浪费了艾芝最后的抢救时间。

此后十一年，穆江把这份愧疚埋进每一道榫卯里。他回乡、不再进城、对"节"的偏执、身上那股艾草味、不看人眼的习惯——全都是同一种愧疚的不同面具。

这段内容与主线直接相关：它解释了艾芝之死的完整经过，也把穆江这个看似"日子人"的NPC，与财阀的复仇线、道士的施法线、河水的污染线紧紧扣在一起。

### 触发条件

* 玩家已解开木雕谜题；
* 且满足以下任意一项：

## 工匠专属互动：手艺退步的发现

工匠角色可以在工坊里仔细端详穆江近年的作品，发现一个反常现象：穆江2014年之前的木器，榫卯严丝合缝、纹路顺达；2014年之后的作品，表面依然光鲜，细看却处处"不合节"——榫角有微妙的错位，纹路被强行修正过，火燎定形的痕迹也不如从前稳定。

但如果工匠进一步说明（或通过检定DC13），穆江会愣住，然后第一次正视自己的手：

他会承认，自从皈依利库伊、每天喝村里的水之后，他做活"不累了"，但手却越来越不听使唤。他一直以为是自己年纪大了，经工匠一提醒才意识到不对。

* 穆江的"快乐"和"不累"是污染的表现，手艺退步是证据；

* 如果工匠愿意，可以帮穆江校准一件作品，穆江好感+1，并额外赠送一支木簪。

#### 渔夫 于乐

##### 基础设定

于乐是田原村土生土长的渔民，祖上三代都以打渔为生。他水性极好，年轻时能在湍急的河段一口气潜半分钟。妻子早逝，他独自把女儿拉扯大，女儿嫁到县城后，他一人住在湖边码头的渔棚里。

于乐在村里人缘极好——他慷慨、热心、爱张罗，谁家有事他都帮忙。2012年他办的那场烧鱼宴，至今仍是村民津津乐道的美谈。

他不知道的是，那场烧鱼宴正是全村污染加速的转折点。2012年他发现河里的鱼全死了，本该警觉，却因为道士一句"利库伊赐福，死鱼亦是圣物"而办了宴席，把死鱼分给全村吃下。此后村里原本对河水有疑虑的人不再质疑，污染从此长驱直入。

于乐至今对此毫不知情。他依然记得那天的鱼"格外鲜甜"，逢人就夸自己那手烧鱼的手艺。

##### 人物特点：见人就让吃鱼

于乐见人的第一反应永远是"吃鱼没？"

无论来者是村长、外乡人还是路过的野狗，他都会从渔棚里端出点什么——腌鱼干、熏鱼条、刚煮好的鱼汤。他的渔棚里永远备着几条鱼，用粗盐腌着，挂在房梁上。玩家第一次接近码头，他会隔着老远喊：
> "来来来，吃鱼没？刚打上来的，甜得很！"

这种热情并非虚伪——于乐是真心觉得鱼好吃，真心想分享。他从小吃河鱼长大，2012年之后他越发觉得河鱼"比从前鲜甜"，把这当成利库伊的恩赐。他不知道"鲜甜"是污染的味道，也不知道自己分享出去的每一口鱼都在加深别人的污染。

这种"见人就让吃鱼"的习惯，是他作为渔民表达善意的唯一方式——他不会说客套话，不会送别的礼，只会把最好的鱼分给别人。在田原村这个偏僻地方，鱼就是他的语言。

玩家如果接受他的鱼，会被污染一次（与"渔夫吃水草"并列的污染点之一）。

##### 人物特点：对"下水"的执念

于乐坚信"不吃鱼的渔民不是真渔民，不下水的渔民不是真渔民"。

他会反复劝玩家下水游泳，尤其看到运动员时会格外兴奋：
> "你这身板，是练过的吧？下河游两圈，这水养人！"
> "我年轻时候一口气能潜半分钟，你试试，水底凉快得很。"

如果运动员接受建议下水抓鱼，会被污染一次。

这个执念源于于乐的骄傲。他是田原村公认水性最好的人，这辈子最得意的事就是年轻时在河里救过落水的孩子、打过最大的鱼。2012年之后，他觉得河水"比从前更温顺、更养人"，下水成了一种享受。他把这份享受当成好意分享给所有人，却不知道自己分享的是污染。

他不知道水有毒。在他的感知里，水越来越"甜"、鱼越来越"鲜"，这些都是利库伊的恩赐，是日子越过越好的证明。

这条信息让玩家确认：2012年烧鱼宴是污染加速的关键节点，道士在其中起了推动作用。但于乐本人是"被利用的善意"，不是加害者。

当玩家深入调查道士时，发现他不是纯粹的坏人。

**线索来源**：
- 道馆里有封印仪式的残留材料和失败痕迹
- 道士写给网红的匿名信中包含"当心穿蓝衣黑裤的人"——穿蓝衣黑裤的正是道士自己被控制时的装扮
- 林德山的疯话日记记录"道士有时犹豫，有时流畅"——半人半傀儡的状态
- 工头老龚的日记提到"道士刚来时试图阻止村民喝河水，但后来变了"
- 2014年艾芝之死——道士施法时的状态与平时不同

**玩家心理**："道士也是受害者？那真正的问题出在哪？摧毁祭坛到底对不对？"

### 第三层（反转2）：隐士才是幕后真凶

当玩家跟随隐士准备"摧毁祭坛"时，发现关键矛盾。

**线索来源**：
- 林德山疯话日记："祭坛在压水，拆了水就涨了"——与隐士说的"摧毁祭坛=净化"矛盾
- 隐士2005年"出走修炼"——在最困难的时候离开，不是拯救者的行为
- 工头老龚日记："2000年事故前有个陌生人在村子附近转悠"
- 运动员父亲日记时间线矛盾：婴儿是5月10日出生的，但事故是4月15日——有人在事故后还在山洞活动
- 2000年事故的起因不是偶然——隐士在外面散布了"山里有青铜文物很值钱"的消息，引诱施工队起了贪念
- 隐士让玩家"找武器防身"——最终仪式需要武装的标记者自愿入水

**玩家心理**："隐士一直在利用我！摧毁祭坛是错的！网红是标记者！我差点害了所有人！"

### 反转的叙事节奏

```
游戏前1/3：第一层真相逐渐浮现（水有问题、利库伊是邪神）
          ↓
          玩家以为破案了，准备去山洞摧毁祭坛
          ↓
游戏中1/3：第二层真相浮现（道士是堕落的封印者）
          ↓
          玩家开始犹豫，但隐士说"道士不可信，跟我走"
          ↓
游戏后1/3：第三层真相浮现（隐士是幕后真凶）
          ↓
          玩家必须在最终抉择前发现真相并做出正确判断
```

## 6. 线索推理链

### 6.1 核心推理链设计

线索不再是孤立的"关键词触发"，而是需要组合才能看到全貌的拼图。

#### 推理链A：水的真相

```
[村长否认污染] + [林德山赞美圣水]
  → 两人态度异常，水一定有问题
    → [工厂搬迁真相：2015年因水质太差退出]
      → 工厂不是污染源，污染源在上游
        → [运动员父亲日记：河水不对劲]
          → 污染至少从2012年（烧鱼宴）开始
            → [林德山疯话日记：甜味越来越浓]
              → 污染在持续加重
```

#### 推理链B：2000年事故真相

```
[公共信息：2000年工地意外] → 去问工头老龚
  → [老龚日记/录音：陆羽和龚泽发现青铜鼎，试图搬出时坍塌]
    → [新闻报道：龚泽死后妻子王芳早产自缢，婴儿随河漂流]
      → [运动员父亲日记：2000年救起河中竹篮婴儿]

          → [录音细节：青铜鼎破碎后"不存在的低频嘶叫"]
            → 利库伊在2000年被释放
```

#### 推理链C：道士的双面性（修订新增）

```
[道士来村时间2010年] + [隐士2005年出走]
  → 道士来时隐士不在
    → [道馆Polish解谜：封印仪式材料]
```

```
  → 矛盾！谁在说谎？
    → [隐士2005年出走修炼：为什么在最困难时离开？]
      → [老龚日记：2000年事故前有陌生人在村子附近]
```

## 8. 结局系统（修订版：10种结局）

### 8.1 结局判定流程

```
                    污染度=6？
                   /        \
                  是          否
                  |            |
              迷途结局    是否皈依利库伊？
                            /        \
                          是          否
                          |            |
                      信仰判定      游说判定+隐士真相判定
                      /     \        /     |     |    \
                    成功   失败   成功   成功   失败  失败
                     |       |    +真相  +未觉   +真相  +未觉
                  皈依    献祭    |       |      |       |
                  结局    结局    封印   净化   奉献   路人
                                  结局   结局   结局   结局

                                                        消灭结局（游说失败+未击杀道士+未觉真相）
```

### 8.2 结局详情

#### 3.1 摆烂结局（原版保留）
**触发**：未找到山洞位置，无从得知真相。来田原村旅游的。
**内容**：你离开了田原村，什么都没发现。村里的故事继续，利库伊继续扩散。

#### 3.2 皈依结局（原版保留+修订）
**触发**：选择皈依利库伊 + 信仰判定成功 + 污染度<6
**内容**：你皈依了利库伊教，融入田原村的流水中。在铲除了碍手的隐士之后，没有人能够阻止利库伊。
**修订**：隐士被铲除后，利库伊失去了唯一的"完全苏醒"执行者——所以利库伊虽然没有被消灭，但也无法完全苏醒。你成了新的"守护者"——一个被污染的、幸福的守护者。

#### 3.3 献祭结局（原版保留）
**触发**：选择皈依利库伊 + 信仰判定失败 + 污染度<6
**内容**：你决定皈依利库伊教，但未骗过隐士。隐士逃出田原村，将邪教入侵公之于众。在外界干预前，愤怒的道士和村民将你献祭给了利库伊之神。
**修订**：隐士逃跑不是出于正义——他是去完成另一个仪式。你的献祭反而成了他计划的一部分。

#### 3.4 净化结局（原版保留+修订）
**触发**：选择不皈依 + 游说判定成功 + 击杀道士 + **发现隐士真相并修复祭坛**
**内容**：你敏锐地发现利库伊是邪教崇拜。你争取到村民认可，**识破隐士的谎言，修复而非摧毁祭坛**，联合道士清醒时的力量重新封印利库伊。村民得到净化，你拯救了一切。
**修订**：原版的净化结局是"摧毁祭坛"，修订后正确做法是"修复祭坛/重新封印"。直接摧毁祭坛会触发沉没结局。

#### 3.5 奉献结局（原版保留+修订）
**触发**：选择不皈依 + 游说判定成功 + 未击杀道士
**内容**：你成功摧毁了祭坛，消灭了利库伊，但势力单薄。疯狂的道士比你更具煽动性，最终将你消灭。利库伊影响将在一段时间后散去，但你永远牺牲在了成功的前夜。
**修订**：如果你摧毁了祭坛但没发现隐士真相，利库伊不会"散去"——它只是失去了祭坛的制衡后暂时蛰伏。道士清醒时试图重新封印但失败，你们都死了。

#### 3.6 消灭结局（原版保留）
**触发**：选择不皈依 + 游说判定失败 + 未击杀道士
**内容**：你发现邪教势力的猖獗但为时已晚。你的努力终究无法战胜全村人的力量，你只能眼睁睁看着道士将你消灭。

#### 3.7 迷途结局（原版保留）
**触发**：污染度=6
**内容**：你仿佛听到利库伊的召唤，向山洞走去。村民看着你，眼神带着敬意。你走进黑漆漆的山洞，看到深处的水潭。水潭倒映着你扭曲涣散的脸。更近一些，再近一些，一声声呼唤促使你蹲下身跳进冰冷的水里。水...利库伊...你就在我的身边吗...利...

#### 3.8 路人结局（原版保留）
**触发**：选择不皈依 + 游说判定失败 + 击杀道士
**内容**：你见证了田原村的落寞，每个人在利库伊的水流中苟延残喘却不自知。你杀死了道士，除掉了邪恶的传教者。至少你安全了。你走到村口向村民告别，无力改变这里的一切。

#### 3.9 沉没结局（修订新增）
**触发**：选择不皈依 + 游说判定成功/失败 + **摧毁了祭坛但未发现隐士真相** + 网红在场
**内容**：你按照隐士的指引摧毁了祭坛——但祭坛是最后的制衡。失去了祭坛的压制，思源湖水位暴涨。网红在利库伊的召唤下走向水潭，你来不及阻止。湖水淹没了整个田原村，利库伊完全苏醒。你站在山顶，看着曾经的世外桃源沉入黑色的水中。

#### 3.10 真相结局（修订新增·完美结局）
**触发**：选择不皈依 + 游说判定成功 + 击杀道士 + **发现隐士全部真相** + **修复祭坛** + **说服道士清醒时合作** + 网红未被污染入水
**内容**：你揭开了三层真相——利库伊是远古封存意识、道士是堕落的封印者、隐士是幕后真凶。你说服了道士在清醒时与你合作，修复了祭坛，重新封印了利库伊。隐士的计划彻底失败。林德山终于放下了疯癫的伪装，在祭坛前为亡妻秀云烧了一炷香。村长交出了保险柜里的猎枪，说"终于不用再装了"。你离开田原村时，河水开始慢慢变清。

### 8.3 信仰判定（原版保留）

击杀神秘人（隐士）则自动判定成功。其余情况必须两人都信仰判定成功才算成功。

| 职业 | 信仰判定条件 |
|------|-------------|
| 工匠 | 是否愿意长久定居田原村 |
| 财阀 | 是否愿意定居+建立工厂合作生产矿泉水（任一同意即可） |
| 运动员 | 是否愿意留在田原村做体育老师 |
| 医生 | 是否愿意留在田原村做乡村医生 |
| 网红 | 是否愿意在直播中宣扬利库伊（非财阀同伴）/带货田原村大米（财阀同伴） |

### 8.4 游说判定（原版保留+修订）

劝说成功数量≥3则判定成功。
- 有医生并发现干燥剂治愈作用：+1
- 有运动员：+0.5
- 有网红：+0.5
- 有攻击村民/村长行为：-1

**修订新增**：发现隐士真相后，可选择说服道士清醒时合作——如果成功，道士的力量可用于修复祭坛，等同于游说判定+2。

### 11.3 支线交织的叙事效果

五个职业的支线不是平行的，而是**互相照亮**的：

- 工匠支线揭示的"甘母艾芝之死"，让财阀的复仇有了具体目标
- 财阀支线揭示的"甘父通话"，让工匠知道了父亲误判的后果
- 运动员支线揭示的"救起竹篮婴儿"，让医生找到了自己的身世
- 医生支线揭示的"龚泽之死"，让运动员知道了救起的婴儿是谁
- 网红支线揭示的"利库伊诅咒"，让所有人明白了网红的特殊性

**玩家之间的信息共享是关键**——每个职业的支线都为其他职业提供了关键拼图。

| 任何饮用河水的行为 | — |

### 12.2 污染等级与可感知异常（修订核心）

详见第1.2.2节。核心设计：**污染不是隐形数字，而是可感知的异常**。每升一级，玩家的游戏体验都会发生变化——从UI描述变化到对话建议被篡改，再到地点名称改变和立绘异变。

### 12.3 倒计时机制（修订新增）

除了污染度，增加**时间推进事件链**作为软倒计时：

| 阶段 | 触发条件 | 事件 |
|------|----------|------|
| 第1阶段 | 玩家获得3条线索后 | 某个不重要村民"没来打水"——村长说"可能去走亲戚了" |
| 第2阶段 | 玩家获得6条线索后 | 村长开始焦虑，暗示"道士说最近需要加大献祭" |
| 第3阶段 | 玩家获得9条线索后 | 林德山告诉玩家"湖水涨了，你看，又涨了"——思源湖水位实际在上升 |
| 第4阶段 | 玩家获得12条线索后 | 如果玩家不去后山，会有具名NPC（如农夫老牛）失踪 |

**效果**：给玩家明确信号——你不行动，就会有人死。但不强制时间限制，只是增加紧迫感。

## 13. DM/开发者笔记


### 13.1 修订版DM提示（新增）

1. **三层反转的节奏控制**：不要让玩家太快发现第二层和第三层。第一层真相可以在前1/3浮现，第二层在中间1/3，第三层在后1/3。
2. **隐士的表演**：隐士NPC的扮演者必须表现得真诚、理性、有逻辑。他说的每一句话都是真的——除了"摧毁祭坛可以净化"这一个关键谎言。
3. **道士的双重状态**：道士NPC的扮演者需要在"清醒"和"被控制"之间切换。清醒时犹豫、痛苦、给出隐晦提示；被控制时流畅、空洞、传播信仰。
4. **村长的"知道"**：村长NPC的扮演者全程表现"不知道"，但如果玩家出示铁证，可以有"你以为老头子不知道吗？"的崩溃时刻。
5. **林德山的疯话**：林德山NPC的扮演者需要在疯话中穿插真实信息。真实信息要用隐语表达，只有引用他的逻辑反问时才短暂清醒。
6. **网红的特殊性**：网红玩家不应该过早知道自己是"被标记的人"。这个真相应该在网红支线解锁后，由玩家自己发现。
